<Update label="2026-6-1" tags={["版本", "功能", "优化"]} description="v0.5.4">
  ## 更改

- 版本号更新至 `0.5.4`，并让 native bridge 构建直接读取项目 Git 版本信息，减少手工维护版本号的偏差
- 新增服务通知语言运行时和今日流量读取能力，优化 Tun / Root Tun 服务通知的状态文案与本地化展示
- 强化 Sub-Store 下载体验，补充下载进度、状态提示、取消/重试流程和健康检查相关设置
- Meta 特性页继续完善 GeoX 文件更新流程，增强校验、进度、错误提示与设置备份/恢复链路
- 修复运行时代理选择同步问题，减少进入代理页或服务重载后节点选择状态不一致的情况
- 继续打磨页面动效、按钮按压反馈、底部栏滚动隐藏、页面滚动位置恢复和危险操作确认样式
- 优化代理页、日志页、流量统计、ACG 首页、配置覆写列表与编辑器相关交互细节
- 调整应用启动、主题与偏好设置中的若干文案和布局细节，补充中英文与繁体中文翻译

  [下载链接](https://github.com/amamiyakokoro/KokoroBox/releases/tag/v0.5.4)
</Update>

<Update label="2026-5-6" tags={["Beta", "功能", "优化"]} description="v0.5.3 (Beta) Preview">
  ## 更改

- 版本标识更新为 `0.5.3 (Beta)`，作为 v0.5.3 Beta 预览发布
- 引入 Sora 原生代码编辑器，替换旧版轻量文本编辑方案，改进大配置编辑、全屏编辑与配置预览体验
- 编辑器主题同步 Material Design 3 色彩体系，补充行号、当前行、选区、文本操作浮窗与括号高亮等编辑器配色
- 新增应用数据管理能力，支持用户设置备份/恢复、应用数据清理以及托管日志导出
- Meta 特性页增强 GeoX 文件下载、校验与进度展示，并改用 Material 3 Expressive 波形进度组件
- 代理页新增代理模式选择说明，优化节点/代理组交互、排序、测速与面板入口
- 底部导航栏自动隐藏逻辑重构，减少滚动场景下误触和遮挡
- 统一 MD3 语义图标目录，逐步替换旧图标集，提升页面视觉一致性
- 底部弹窗迁移到窗口级实现，优化高度、滚动与关闭体验
- 移除 Lite 构建模块，精简项目结构与维护成本
- README、第三方致谢与更新日志同步整理

  [下载链接](https://github.com/amamiyakokoro/KokoroBox/releases/tag/v0.5.3-Beta-preview)
</Update>

<Update label="2025-11-27 ~ 2026-4-9" tags={["归档", "历史"]} description="MD3 化前历史摘要">
  ## 归档说明

  MD3 化之前的逐版本流水账已合并为摘要，避免当前更新页过长。完整标签、下载资产和原始发行记录仍可在 GitHub Releases 查看。

  ## 主要内容

- 从早期测试版逐步独立出基于 mihomo 内核的 Android 客户端，完成包名变更、初始化流程、多语言、订阅导入、二维码/剪贴板导入、外部控制和 Web 面板等基础能力
- 持续增强代理和节点体验，包括代理启动优化、节点选择与排序、延迟测试、代理组图标/旗帜显示、通知栏快捷切换、Root Tun、连接页面与流量统计
- 引入并完善覆写系统、运行时配置预览、Rust 覆写解析、配置编辑器语法检查/部分补全、Meta 特性和自定义分流入口
- 持续打磨主题取色、导航栏、Topbar 模糊、页面动画、弹窗性能、配置排序、访问控制和首页 ACG / 一言体验
- 移除部分旧实验能力和第三方服务，包括液态玻璃、Sentry 跟踪器和 EMAS 推送更新，并持续优化稳定性、打包体积和后台资源释放

  [查看完整历史](https://github.com/amamiyakokoro/KokoroBox/releases)
</Update>
